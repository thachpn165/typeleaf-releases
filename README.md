# TypeLeaf

Ứng dụng macOS để gõ lại từng trang sách và thư giãn cùng nhịp bàn phím.

Repo này dành cho bản cài, thông tin phát hành và cập nhật của TypeLeaf. Hiện chưa có bản cài native được phát hành.

Khi có bản mới, ứng dụng sẽ thông báo để bạn bấm cập nhật. Người dùng không cần tài khoản hoặc token GitHub.
